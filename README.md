## Projeto desenvolvido ao longo das sprints

Nas etapas finais do programa, trabalhei na construção de um pipeline para análise de dados de filmes e séries.

O fluxo desenvolvido envolveu:

1. ingestão de arquivos CSV no Amazon S3;
2. coleta de dados da API do TMDB com Python;
3. execução da coleta por meio do AWS Lambda;
4. armazenamento dos dados em uma Raw Zone;
5. transformação e limpeza com AWS Glue e Apache Spark;
6. organização dos dados nas camadas Trusted e Refined;
7. armazenamento em formato Parquet;
8. modelagem de tabelas fato e dimensão;
9. consultas SQL utilizando Amazon Athena;
10. criação de visualizações e dashboards no Amazon QuickSight.

Essa experiência proporcionou uma visão prática do ciclo de dados, desde a coleta e o armazenamento até o processamento, a análise e a apresentação das informações.
