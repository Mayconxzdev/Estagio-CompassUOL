# Evidências do Desafio de Filmes e Séries

## Introdução
Este documento contém evidências e documentação sobre a realização do Desafio de Filmes e Séries. Aqui, serão apresentadas imagens, prints e explicações sobre cada etapa executada no projeto.

## Estrutura do Projeto
O projeto é organizado da seguinte forma:

- **src/**: Contém o código-fonte da aplicação.
  - **lambda_function.py**: Função principal da AWS Lambda.
  - **tmdb_api.py**: Interação com a API do TMDB.
  - **s3_utils.py**: Funções utilitárias para o Amazon S3.
  - **types/index.py**: Definições de tipos e interfaces.
  
- **requirements.txt**: Lista de dependências do projeto.
- **README.md**: Documentação do projeto.
- **evidencias/**: Contém evidências e documentação do desafio.

## Etapas do Desafio

### Etapa 1: Preparação do Ambiente
- Configuração do ambiente de desenvolvimento.
- Instalação das dependências necessárias.

### Etapa 2: Implementação da Função Lambda
- Desenvolvimento da função `lambda_function.py` para orquestrar a ingestão de dados.
- Implementação das chamadas à API do TMDB.

### Etapa 3: Persistência dos Dados
- Utilização do `s3_utils.py` para gravar os dados no Amazon S3.
- Agrupamento dos dados em arquivos JSON com no máximo 100 registros.
